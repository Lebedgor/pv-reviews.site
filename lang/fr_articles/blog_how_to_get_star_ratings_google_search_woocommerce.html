Comment obtenir des étoiles dans les résultats Google pour WooCommerce (guide 2026)

Mis à jour le 9 septembre 2026 · 7 min de lecture

Les étoiles jaunes dans les résultats Google sont l'attention la moins chère qui soit — en fait, elle est gratuite. Les listes avec étoiles et nombre d'avis obtiennent systématiquement un CTR plus élevé que les simples liens bleus, parce qu'une note répond à la première question de l'internaute (« ce produit est-il bon ? ») avant même le clic.

Pour une boutique WooCommerce, obtenir ces étoiles comporte deux parties : recueillir de vrais avis et les exposer en données structurées que Google peut interpréter. Ce guide couvre les deux — et montre comment PVR Media Reviews, un plugin gratuit d'avis photo et vidéo pour WooCommerce, automatise la seconde partie.

✍️ Étape 1 : avoir quelque chose qui mérite une note

Les données structurées reflètent la réalité. Google suspend les résultats enrichis des pages dont le balisage ne correspond pas au contenu visible, donc le chemin durable commence par un véritable flux d'avis — un parcours que vos clients complètent réellement.

Un formulaire demandant une note, une phrase de contexte et éventuellement une photo suffit. Les médias sont le multiplicateur de confiance le plus puissant : les avis photo et vidéo sont le contenu que les acheteurs capturent et partagent, et ils signalent l'authenticité autant aux acheteurs qu'aux moteurs de recherche.

👀 Étape 2 : montrer l'histoire de la note sur la page

Les évaluateurs qualité de Google — et vos visiteurs — attendent que la page visible corresponde aux données structurées. Un onglet d'avis crédible affiche la note moyenne, le nombre, la répartition par étoiles et les avis individuels derrière.

🤖 Étape 3 : les données structurées que Google lit

Google n'interprète pas les étoiles dessinées par votre thème. Il lit Schema.org JSON-LD dans le HTML de la page. Pour les étoiles d'avis d'un produit, deux structures comptent dans le schéma Product :

  1. aggregateRating — la note moyenne et le nombre total d'évaluations.
  2. review — les avis individuels : auteur, date, corps et chaque note.
{
  "@context": "https://schema.org",
  "@type": "Product",
  "name": "Premium Leather Travel Bag",
  "aggregateRating": {
    "@type": "AggregateRating",
    "ratingValue": "4.8",
    "reviewCount": "42",
    "bestRating": "5",
    "worstRating": "1"
  },
  "review": [{
    "@type": "Review",
    "author": { "@type": "Person", "name": "Sarah Jenkins" },
    "datePublished": "2026-08-10",
    "reviewBody": "Incredible leather quality — and the photos
                   from other buyers matched exactly.",
    "reviewRating": {
      "@type": "Rating",
      "ratingValue": "5",
      "bestRating": "5",
      "worstRating": "1"
    }
  }]
}
Point clé

Les étoiles en CSS sont invisibles pour Google. Seul le JSON-LD lisible par machine compte. Si votre thème dessine des étoiles mais que rien ne génère de données structurées, vos produits n'afficheront jamais d'étoiles dans la recherche.

⚙️ Étape 4 : automatiser (et éviter le conflit classique)

C'est là que les sites WooCommerce bloquent habituellement : WooCommerce par défaut émet son propre schéma produit, et les plugins SEO comme Yoast ou Rank Math émettent le leur. Un plugin d'avis qui ajoute un troisième bloc parallèle crée des doublons — et les doublons sont signalés dans Google Search Console au lieu de rapporter des étoiles.

PVR Media Reviews résout cela en s'intégrant au système qui produit déjà votre schéma produit :

🛒
WooCommerce natif
Injecte Review et AggregateRating dans woocommerce_structured_data_product — le JSON-LD que génère WooCommerce lui-même.
🟣
Compatible Yoast SEO
Se raccorde au graphe de schéma produit de Yoast (wpseo_schema_product), de sorte que les données d'avis fusionnent dans un bloc propre au lieu de le dupliquer.
🔵
Compatible Rank Math
S'intègre à rank_math/schema/product de la même manière — un seul graphe, sans conflit.
⚙️
Zéro édition du thème
Aucune modification de template, aucun snippet dans functions.php, aucun troisième plugin de schéma. Les notes viennent automatiquement de vos avis WooCommerce approuvés.

Les données derrière le balisage sont vivantes : aggregateRating est recalculée à partir des avis approuvés, et les dix derniers avis approuvés sont émis comme objets Review individuels — exactement le signal de « contenu frais » que les consignes de Google encouragent. Tout cela fait partie du plugin gratuit ; ce n'est pas derrière la licence Pro.

🔍 Étape 5 : vérifier avec les outils de Google eux-mêmes

  1. Publiez au moins un avis approuvé avec note sur un produit de test (les réglages d'auto-approbation du plugin accélèrent cela).
  2. Ouvrez le test de résultats enrichis de Google.
  3. Saisissez l'URL de votre page produit et lancez le test.
  4. Confirmez que l'élément Product est détecté avec aggregateRating et review listés sans erreur.
  5. Répétez sur une page où Yoast ou Rank Math est actif — l'objectif de l'intégration est qu'il n'y ait aucun avertissement de schéma dupliqué.

⏳ Une note sur les délais

Un balisage valide rend un produit candidat aux étoiles d'avis. Google décide quand (et s'il) les afficher, et cela arrive généralement quand les avis s'accumulent naturellement. Une raison de plus de rendre le dépôt d'un avis — idéalement avec photo — le plus simple possible.
