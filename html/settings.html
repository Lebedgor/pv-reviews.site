All Plugin Settings

Complete reference of every configuration option in the PVR Media Reviews admin panel, organized by settings tab.

General Settings

Free Auto-approve Reviews Select which reviews should be published automatically without moderation. Options: Disabled (manual moderation for all), From customers (auto-approve reviews from buyers of the product), From registered users (auto-approve from logged-in users), From all users (auto-approve everything).
Free One Review per Product Limit each user to one review per product. When enabled, a customer who already left a review cannot submit another one for the same product. Default: enabled.
Free Who Can Review Control who is allowed to leave reviews. Options: All visitors (anyone, including guests), Registered users (only logged-in users), Only customers (only users who purchased the product).
Free Who Can Reply Control who can reply to reviews. Same options as above: All visitors, Registered users, or Only customers.
Free Who Can Vote Control who can mark reviews as "helpful". Options: All visitors, Registered users, or Only customers.
Free Default Reply Status Default moderation status for store replies. Options: Enabled (auto-approved, shown immediately) or Disabled (held for moderation before publishing).
Free Pros & Cons Enable separate "Pros" and "Cons" fields in the review form, allowing customers to list specific advantages and disadvantages of the product. Default: enabled.
Free Phone Field Show an optional phone number field in the review form. Default: disabled.
Free City Field Show an optional city field in the review form, letting reviewers share their location. Default: disabled.
Free Privacy Policy URL URL to your privacy policy page. When set, a consent checkbox linking to this URL is shown in the review form.

Limits & Anti-spam

Free Review Min Length Minimum number of characters required for a review. Prevents empty or very short reviews. Default: 10.
Free Review Max Length Maximum number of characters allowed in a review. Default: 5000.
Free Name Min Length Minimum number of characters for the reviewer's name. Default: 3.
Free Name Max Length Maximum number of characters for the reviewer's name. Default: 64.
Free Reply Min Length Minimum number of characters required for a reply to a review. Default: 10.
Free Reply Max Length Maximum number of characters allowed in a reply. Default: 2000.
Free Pros/Cons Max Length Maximum number of characters for each Pros and Cons field. Default: 500.

Security

Free Reviews / Day (per IP) Maximum number of reviews a single IP address can submit per day. Prevents spam from repeat visitors. Default: 10.
Free Users / Day (per user) Maximum number of reviews a single registered user can submit per day. Default: 20.
Free Media Files / Day Maximum number of media files (photos + videos) a single IP can upload per day. Default: 12.
Free Media Weight (MB) / Day Total weight limit (in MB) of all media files a single IP can upload per day. Prevents storage abuse. Default: 1500 MB.
Free Hidden Field Protection (Honeypot) Enable a hidden form field that bots automatically fill in, allowing the system to detect and reject automated spam submissions. Default: enabled.
Free Enable reCAPTCHA v3 Add Google reCAPTCHA v3 verification to the review form for advanced bot protection. Default: disabled.
Free reCAPTCHA Site Key Your Google reCAPTCHA v3 site key. Required when reCAPTCHA is enabled.
Free reCAPTCHA Secret Key Your Google reCAPTCHA v3 secret key. Required when reCAPTCHA is enabled.
Free reCAPTCHA Threshold Minimum score (0.0–1.0) required to pass reCAPTCHA verification. Lower values are more lenient. Default: 0.5.
Free Allowed Photo MIME Types Comma-separated list of allowed photo file extensions. Default: jpg, jpeg, png, webp.
Free Allowed Video MIME Types Comma-separated list of allowed video file extensions. Default: mp4, webm, mov.

Media — Image Settings

Free Target Resolution Maximum image resolution after server-side processing. Images larger than this are resized. Options: HD (1280×720), Full HD (1920×1080), QHD (2560×1440), 4K UHD (3840×2160). Default: Full HD.
Free Global Quality JPEG/WebP compression quality (40–100). Higher values preserve more detail but increase file size. Default: 85.
Free Max Photos per Review Maximum number of photos a customer can attach to a single review. Default: 5.
Free Photo Size Min (MB) Minimum file size for photo uploads. Files smaller than this are rejected. Default: 0.1 MB.
Free Photo Size Max (MB) Maximum file size for photo uploads. Files larger than this are rejected. Default: 8 MB.
Free Watermark Image Upload a watermark image to automatically overlay on all user-submitted photos. Leave empty to disable.
Free Watermark Position Position of the watermark overlay on photos. Options: Disabled, Top-left, Top-right, Bottom-left, Bottom-right, Center.
Free Watermark Width (%) Watermark width as a percentage of the image width. Default: 20%.
Free Max Avatar Size (MB) Maximum file size for avatar uploads. Default: 5 MB.
Free Avatar Target Size (px) Avatars larger than this (in pixels) are automatically resized on upload. Default: 500 px.

Media — Video Settings

Free Target Resolution Maximum video resolution after client-side compression. Options: HD (1280×720), Full HD (1920×1080), QHD (2560×1440), 4K UHD (3840×2160). Default: HD.
Free Target Bitrate Target video bitrate for compression. Higher bitrates produce better quality but larger files. Options: 2500 kbps (HD), 5000 kbps (Full HD), 8000 kbps (QHD), 16000 kbps (4K UHD). Default: 5000 kbps.
Free Max FPS Maximum frames per second for compressed videos. Videos with higher FPS are downsampled. Default: 30.
Free Compress Above (MB) Videos larger than this size (in MB) are automatically compressed in the browser before upload using modern MediaRecorder API + Canvas. Zero server CPU load. Default: 50 MB.
Free Max Videos per Review Maximum number of videos a customer can attach to a single review. Default: 3.
Free Video Size Min (MB) Minimum file size for video uploads. Default: 0.1 MB.
Free Video Size Max (MB) Maximum file size for video uploads before compression. Default: 500 MB (fully configurable).
Free Video Duration Min (sec) Minimum video duration in seconds. Shorter videos are rejected. Default: 3 sec.
Free Video Duration Max (sec) Maximum video duration in seconds. Longer videos are rejected. Default: 120 sec.

Media — Thumbnail Settings

Free Grid Thumbnail Width Width in pixels of thumbnails shown in the gallery grid on the product page. Default: 100 px.
Free Grid Thumbnail Height Height in pixels of thumbnails in the gallery grid. Default: 100 px.
Free Modal Preview Width Width in pixels of the image preview shown in the detail modal. Default: 400 px.
Free Modal Preview Height Height in pixels of the image preview in the detail modal. Default: 400 px.
Free Lightbox Image Max Width Maximum width in pixels of images displayed in the full-screen lightbox. Default: 1920 px.
Free Lightbox Image Max Height Maximum height in pixels of images in the lightbox. Default: 1080 px.
Free Grid Thumbnail Quality Compression quality (40–100) for grid thumbnails. Default: 100.
Free Modal Preview Quality Compression quality (40–100) for modal preview images. Default: 100.
Free Lightbox Quality Compression quality (40–100) for full-screen lightbox images. Default: 90.

Emails & Notifications

Free Store Logo Logo displayed in email headers. Leave empty to use your site's custom logo.
Free Store Name Store name shown in email headers and footers. Leave empty to use your WordPress site name.
Free Store Phone Phone number displayed in emails. Leave empty to use the WooCommerce store phone.
Free Contact Email Contact email address shown in the email footer.
Free Admin Email Email address that receives new review notifications. Default: WordPress admin email.
Free From Name Sender name in email headers. Default: your WordPress site name.
Free From Address Sender email address in email headers. Default: admin email.
Free Confirmation Email Subject Subject line for the confirmation email sent to customers after review submission.
Free Notify Admin on New Review Send an email notification to the admin when a new review is submitted. Default: enabled.
Free Confirmation to Customer Send a confirmation email to the customer after their review is submitted. Default: enabled.
Free Notify Customer on Reply Send an email to the customer when the store replies to their review. Default: enabled.

Coupon Rewards PRO

Pro Enable Coupon Rewards Automatically issue a unique WooCommerce coupon code to customers after their review is approved/published.
Pro Discount Type Type of discount for generated coupons. Options: Percentage discount, Fixed cart discount.
Pro Reward Amount — Text Review Discount amount given for a text-only review (no media). Default: 5.
Pro Reward Amount — Photo Review Discount amount given when the review includes photos. Default: 10.
Pro Reward Amount — Video Review Discount amount given when the review includes videos. Default: 15.
Pro Coupon Validity (days) Number of days the generated coupon remains valid after issuance. Default: 30.
Pro Minimum Order Amount Minimum cart total required to use the coupon. Default: 0 (no minimum).
Pro Exclude Sale Items Prevent the coupon from being applied to products already on sale.
Pro Products (IDs) Comma-separated list of product IDs the coupon can be used on. Leave empty for all products.
Pro Exclude Products (IDs) Comma-separated list of product IDs the coupon cannot be used on.
Pro Categories (IDs) Comma-separated list of category IDs the coupon can be used on.
Pro Exclude Categories (IDs) Comma-separated list of category IDs the coupon cannot be used on.
Pro Email Subject Subject line for the coupon reward email. Supports placeholders: {customer_name}, {coupon_code}, {coupon_amount}, {expiry_days}, {site_name}, {shop_url}.
Pro Email Message Body text of the coupon reward email. Supports the same placeholders as the subject line.
Pro Show Notice on Review Form Display a notice on the review form informing customers about the coupon reward. Default: enabled.
Pro Notice Text Custom text for the coupon notice on the review form. Supports placeholders: {text_amount}, {photo_amount}, {video_amount}, {max_amount}.
Pro Minimum Characters for Text Reviews Minimum character count for text-only reviews to qualify for a coupon reward. Prevents very short reviews from getting rewards. Default: 50.

Email Reminders PRO

Pro Enabled Send automatic review request emails to customers after their order is completed.
Pro Delay (Days) Number of days to wait after order status changes to "Completed" before sending the first reminder. Range: 1–90. Default: 7.
Pro Repeat Reminder Send a second reminder email if the customer still hasn't left a review after the first one.
Pro Repeat Delay (Days) Days after order completion to send the second reminder. Range: 2–180. Default: 14.
Pro Exclude Categories Comma-separated list of product category IDs to exclude from reminders.
Pro First Reminder — Subject Subject line for the first reminder email. Supports placeholders: {site_name}, {customer_name}, {order_number}.
Pro First Reminder — Heading Email heading displayed at the top of the first reminder.
Pro First Reminder — Message Body text of the first reminder email. Supports the same placeholders as the subject line.
Pro Second Reminder — Subject Subject line for the second reminder email. Same placeholder support.
Pro Second Reminder — Heading Email heading for the second reminder.
Pro Second Reminder — Message Body text of the second reminder email.
