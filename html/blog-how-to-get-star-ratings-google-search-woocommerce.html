How Google Displays Product Star Ratings (Schema.org JSON-LD)

Google doesn't read the visual stars rendered by your WordPress theme's CSS. Instead, Google's search crawlers parse invisible machine-readable code embedded in your product page headers, formatted according to the Schema.org standard using JSON-LD (JavaScript Object Notation for Linked Data).

For a product to be eligible for review rich snippets in search results, Google requires two critical data structures inside the Product Schema:

  1. aggregateRating: Defines the average score (e.g. 4.8 out of 5) and the total count of verified customer ratings.
  2. review: Contains an array of individual Review objects detailing the author name, date published, review body, and individual rating value.

Example of Valid Review JSON-LD Markup

Below is a clean example of the structured data that search engines expect:

{
  "@context": "https://schema.org",
  "@type": "Product",
  "name": "Premium Leather Travel Bag",
  "aggregateRating": {
    "@type": "AggregateRating",
    "ratingValue": "4.9",
    "reviewCount": "42",
    "bestRating": "5",
    "worstRating": "1"
  },
  "review": [
    {
      "@type": "Review",
      "author": {
        "@type": "Person",
        "name": "Sarah Jenkins"
      },
      "datePublished": "2026-08-10",
      "reviewBody": "Incredible leather quality and plenty of compartments!",
      "reviewRating": {
        "@type": "Rating",
        "ratingValue": 5,
        "bestRating": 5,
        "worstRating": 1
      }
    }
  ]
}
Key Point

Google does not read the visual stars rendered by your theme CSS. It only recognizes machine-readable JSON-LD structured data embedded in your page's HTML header. Without valid Schema.org markup, your stars will never appear in search results.
