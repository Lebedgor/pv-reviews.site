# Screenshots — опись медиафайлов

Описания для встраивания в статью/лендинг. Обновлять при добавлении новых файлов.

**Деплой-копия:** `pv-reviews.site/assets/screenshots/` — сюда папка копируется целиком; для веба рядом с каждым `*.png` генерируется `*.jpg` (1600px, q4), каждый `*.mov` пережимается в `*.mp4` (1920px, 30fps, H.264, faststart). В статьях используются только `jpg`/`mp4`; `png`/`mov` — оригиналы-исходники. Все `<video>` на сайте стартуют с атрибутом `muted` (без звука, звук включается вручную).

**Постеры видео:** `posters/<имя-ролика>.jpg` — кадры, извлечённые из самих `*.mp4` (кадр на 1-й секунде, 1600px, q4), поэтому превью всегда соответствует содержимому ролика. Генерация: `bash make_posters.sh [секунда]` (нужен ffmpeg; запускается из этой папки, перегенерирует постеры для всех `*.mp4`). Новое видео → сначала постер через скрипт, потом `<video … poster="/assets/screenshots/posters/<имя>.jpg">` в статье.

## Видео (mov)

- **all_reviews_page_with_filters.mov** — страница всех отзывов ([pvr_all_reviews]) на витрине: фильтры по категориям/производителям, карточки отзывов с критериями, медиа-миниатюрами и голосованием.
- **avatar_add_and_crop.mov** — процесс добавления аватара и его кропа.
- **review_add_and_publish.mov** — полный флоу отзыва: заполнение формы (аватар с кропом, фото, видео с компрессией) → отправка и загрузка на сервер (upload mode) → переход в админку: отзыв пролистан, показано что всё добавлено, сохранение и публикация → возврат на фронт, обновление страницы, опубликованный отзыв в списке → клик по миниатюре фото внутри отзыва → модалка детального просмотра медиа → несколько перелистываний стрелками → просмотр сжатого видео → закрытие модалки.
- **review_carousel_widget.mov** — виджет «Reviews carousel» на странице WordPress: горизонтальная карусель карточек отзывов с медиа, голосами и Read more, перелистывание слайдов.
- **reviews_grid_widget.mov** — виджет «Reviews grid» на странице WordPress: статическая сетка карточек отзывов (фото товара, аватар автора, звёзды, текст, медиа-миниатюры, голосование).
- **show_media_gallery.mov** — демонстрация медиа-галереи (лента медиа на странице всех отзывов / открытие модалки из галереи).
- **video_compress.mov** — сжатие видео в действии (модалка компрессии во время загрузки).
