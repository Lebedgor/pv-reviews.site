# PVR Media Reviews for WooCommerce — Функциональная карта модуля

> Внутренний справочник для написания статей, лендингов и рекламных материалов.
> Всё подтверждено кодом (скан v1.0.9). При переписывании статей опираться только на факты из этого документа.
> Обновлять при изменении функционала.

## 1. Ключевые позиции для маркетинга (факт-базис)

1. **Данные живут у владельца магазина.**
   Отзывы — нативные WP-комментарии (`comment_type='review'`) + мета. Медиа — в `uploads/pvr-reviews/...` на хостинге магазина, хранятся **относительные пути** (перенос между серверами/ОС безопасен, есть миграция и восстановление «чужих» путей). Внешний SaaS не может удалить контент, отключить его показ или «потерять» медиа после отмены подписки. Всё попадает в обычные бэкапы сайта.

2. **Фото- и видеоотзывы бесплатны навсегда.**
   Загрузка фото/видео, сжатие, галереи, модалки, голосование, ответы, аватары, уведомления, schema — в бесплатной версии без лицензии, без квот на медиа со стороны PVR, без обязательной подписки. Единственные ограничения — честные настройки самого магазина (лимиты файлов/количества) и физические лимиты хостинга (upload_max_filesize) — стандартно для любого WP.

3. **Сжатие видео в браузере — 0% нагрузки на сервер.**
   Видео > порога (по умолчанию 50 МБ, настраивается) пережимается на устройстве клиента: `<video>` → `<canvas>` (цель 1280×720, настраивается) → `canvas.captureStream(fps)` → `MediaRecorder` (предпочтение MP4/H.264, фолбэк WebM VP9/VP8; битрейт 2500/5000/8000/16000 kbps, аудио 128 kbps). Без FFmpeg, без CPU-спайков на хостинге, работает на shared-хостинге. Если результат не меньше оригинала — отправляется оригинал. Видео остаётся видимым в модалке во время сжатия (браузер не рисует кадры скрытого видео — иначе чёрные кадры), есть авто-пауза при уходе со вкладки, ручная пауза/мьют/отмена, очередь файлов.

4. **Безопасность и антиспам без трения.**
   Honeypot (вкл. по умолчанию), опциональный reCAPTCHA v3 с порогом score, лимиты: отзывов с IP/день (10), с аккаунта/день (20), файлов с IP/день (12), суммарный вес с IP/день (1500 МБ) — атомарные SQL-счётчики. Загрузка: nonce + 2-часовой HMAC-токен, двойная проверка MIME (расширение + finfo), детект PHP-обрезки (`file_size===0`), WP_Filesystem, IP-хеши с NONCE_SALT (сырые IP не хранятся), сборка осиротевших загрузок кроном через 24 ч.

5. **Server-side WebP-варианты фото.**
   Три варианта на фото: thumb 100×100 (q100), large 400×400 (q100), popup 1920×1080 (q90) — жёсткий кроп, имена с версией конфига + `?v=` cache-busting, регенерация и очистка кэша из админки.

6. **Менеджер PHP-лимитов (System Info).**
   Определяет SAPI (Apache/LiteSpeed → `.htaccess`; FPM/CGI → `.user.ini`; иначе — только инструкции), бэкап (до 3), запись через WP_Filesystem, живая самопроверка HTTP и авто-роллбэк при 5xx, лог операций (50 записей). Для `.user.ini` — отложенная wp-cron проверка через 6 мин, UI честно предупреждает про ~5 минут. Рекомендуемый профиль: 500M/550M/600M/300s/300s. Ручные инструкции для Apache/FPM/Nginx/shared + готовый текст запроса в саппорт хостинга.

7. **Schema.org из коробки (бесплатно).**
   `Review` (последние 10 одобренных) + `AggregateRating` в JSON-LD: нативный `woocommerce_structured_data_product`, Yoast (`wpseo_schema_product`), Rank Math (`rank_math/schema/product`). Без правок темы, без конфликтов с SEO-плагинами.

8. **Брендированные email-уведомления (бесплатно).**
   Общий HTML-шаблон (градиентная шапка с логотипом, брендинг магазина): 1) админу о новом отзыве (звёзды, pros/cons/city/phone, текст, сетка фото, ссылки на видео, кнопка «Edit review»), 2) автору — подтверждение (только для одобренных; бейдж «live/pending»), 3) автору — ответ на отзыв (два варианта: обычный и от магазина). Дедупликация через мета комментария (comment_post и finish_uploads — разные запросы). Дублирующее письмо WooCommerce отключается. From-имя/адрес применяются только к письмам плагина.

## 2. Бесплатная версия — полный список функций

### 2.1 Форма отзыва (фронт)
- Открытие в модалке кнопкой «Write a review»; deep-link `?pvr_open_review` (используется письмами-напоминаниями).
- Рейтинг 1–5 звёзд (SVG, hover/click).
- Аватар: загрузка (JPEG/PNG/WebP, до 5 МБ) + **мини-модалка кропа** (перетаскиваемый/масштабируемый квадрат, экспорт 200×200 JPEG), серверный ресайз до 500px; аватары гостей и пользователей; страница My Account → Avatar.
- Поля: Pros/Cons (вкл. по умолчанию), City и Phone (отключены по умолчанию, включаются настройкой).
- Имя/email гостя; у вошедших — подстановка данных.
- Медиа-пикер: фото (до 5, 0.01–8 МБ, JPEG/PNG/WebP/GIF) и видео (до 3, 0.1–500 МБ, MP4/WebM/MOV), multiple, drag-zone, лимиты-подсказка, превью с бейджами статуса (Ready/Preparing…/Uploading…/Uploaded), поворот фото ↻, удаление ✕, per-item прогресс.
- Клиентское сжатие фото: ресайз до целевого разрешения (по умолч. 1920×1080), quality 85, EXIF-поворот, **клиентский водяной знак** (позиция из 5+center, ширина в % от изображения).
- Клиентское сжатие видео (см. §1.3): порог, модалка с живым видео и прогрессом, пауза/мьют/отмена, генерация постера (кадр без чёрных кадров), валидация длительности 3–120 с.
- Согласие с политикой конфиденциальности (чекбокс, если задан URL политики) — проверяется и на сервере.
- Валидация в 3 слоя (JS validateFile → JS queueFile с длительностью видео → PHP).

### 2.2 Сценарий отправки (2 фазы)
1. AJAX `pvrev_submit_review` — сохраняется текст отзыва (нативный WP-комментарий), возвращается comment_id.
2. Если есть медиа → форма переходит в **upload mode** (`.pvr-form--uploading`): спиннер, глобальный прогресс с точным байт-процентом (`xhr.upload.onprogress`, прогресс считается от подготовленных payload'ов, а не исходных размеров), per-item прогресс-бары, последовательная загрузка (фото → видео), HTTP 413 → отдельное сообщение про nginx, отмена (abort) не ломает остальные файлы пакета.
3. AJAX `pvrev_finish_uploads` → хук `pvrev_review_media_uploaded` (уведомления/купоны).
4. **Thank-you экран** (`.pvr-form--thankyou`): анимированная галочка, авто-закрытие через 5 с или по кнопке.

### 2.3 Отображение на странице товара
- Полная замена шаблона отзывов WooCommerce (нативное хранение сохраняется).
- **Блок статистики**: средняя оценка, звёзды (full/half/empty), количество, разбивка 5→1 с процентными барами.
- **Customer Media strip** (`#pvr-product-media-showcase`): горизонтальная лента миниатюр, собираемая из карточек отзывов; «Show all media».
- **Карточка отзыва**: аватар (клик — зум), имя, бейдж **Verified Purchase** (проверка `wc_customer_bought_product`), город-чип, звёзды, дата, текст, Pros/Cons, медиа-ряд (фото + видео с play-оверлеем), футер: helpful-голосование + Reply.
- **Модалка «все медиа товара»** (`media-grid-modal`): сетка всех фото/видео продукта, переход к детальному просмотру.
- **Детальная модалка** (`media-review-modal`): слева большой медиа-блок (счётчик, блюр-фон), справа — клоны данных отзыва (автор, текст, thumb-строка, голосование, ответы); prev/next по всем медиа страницы; свайпы (гориз. на десктопе, верт. на мобиле); клавиатура ←/→/Esc; «To all photos and videos»; «Expand» — оригинал в новой вкладке.
- **Кастомный видеоплеер**: play/pause, mute (запоминается в localStorage, по умолч. muted), время, буферизация+прогресс, seek, fullscreen (нативные контролы в fullscreen; iOS `webkitEnterFullscreen`).
- **Helpful voting**: да/нет, один голос с пользователя или IP-хеша, переключение голоса, синхронизация баланса во всех инстансах (карточка, модалка, мобильный слайд).
- **Ответы магазина**: ветвление (1 уровень), бейдж «Support Team», статус-модерация, письмо автору.
- «Show more» (AJAX-догрузка с обновляемой навигацией) + нумерованная пагинация; настраиваемая пер-страница (10).
- Лип-скролл модалок через `syncBodyModalClass()` (единый менеджер всех модалок).

### 2.4 Модерация и доступ
- Auto-approve: нет / покупатели / зарегистрированные / все.
- Кто может отзыв/ответ/голос: все / зарегистрированные / покупатели.
- Один отзыв на товар на email (вкл. по умолчанию).
- Лимиты длины: имя 3–64, отзыв 10–5000, ответ 10–2000, pros/cons 0–500.

### 2.5 Личный кабинет (My Account)
- Endpoints **My Reviews** (список своих отзывов: товар, звёзды, «Pending moderation», pros/cons, медиа, пагинация) и **My Avatar** (загрузка + кроп).

### 2.6 Админка (free)
- Меню: PV Reviews (значок звезды), Reviews, Comments (ответы), Settings; бейджи количества на модерации.
- Список отзывов: фильтры (статус, автор, email, товар, наличие фото/видео, поиск), пагинация 20/стр, bulk approve/hold/delete, удаление с медиа.
- Редактор отзыва: товар (автокомплит + миниатюра), звёзды, verified-buyer тумблер (авто-проверка), автор (автокомплит по юзерам, аватар через wp.media, normalize относительного пути), текст/pros/cons/полезность ±/дата (datepicker), ответ магазина (TinyMCE), критерии (Pro-aware), **медиа: добавление из медиабиблиотеки WP, импорт по одному с постером видео, подписи размеров файлов (formatFileSize), лайтбокс (клавиши, счётчик, видео), удаление**, диф медиа при сохранении, статус-кнопки с мгновенным сохранением.
- Ответы: список (статусы, поиск, bulk), редактор (бейдж Support Team, approve → письмо).
- Настройки (SPA-табы, AJAX, dirty-state guard, тосты, iOS-стиль):
  - **General**: модерация, доступы, поля (pros/cons/phone/city), имя менеджера, privacy URL, пагинация.
  - **Limits & Anti-spam**: символьные лимиты.
  - **Security**: IP/день лимиты (отзывы, аккаунт, файлы, вес), honeypot, reCAPTCHA v3 (site/secret/threshold), разрешённые MIME фото/видео.
  - **Media** (под-табы): Image (разрешение, качество 40–100, лимиты, **watermark: загрузка/позиция/ширина/удаление**), Avatar (размер, целевой px), Video (разрешение, битрейт, fps, порог сжатия, лимиты, длительность), Thumbnails (3 варианта WebP + качества), Maintenance (Clear Image Cache).
  - **Emails & Notifications**: Store Information (логотип через WP Media Manager, имя, телефон, email), Sender Info (admin email, from name/address, subject), тумблеры 3 уведомлений.
  - **Import / Export**: экспорт/импорт настроек JSON, reset to defaults, синхронизация структуры БД; (в Pro-дистрибутиве — ещё сам-обновление и бэкапы плагина).
  - **System Info**: окружение, статусы применения лимитов, текущие значения, форма изменения, содержимое .user.ini/.htaccess, ручные инструкции 4 способами.
- Pro-табы рендерятся как превью (grayscale, locked) до активации лицензии — витрина Pro.

### 2.7 i18n
- Английский — исходный язык; JSON-фолбэк каталоги (en_US, ru_RU; есть es_ES/fr_FR файлы), фильтруемо (`pvrev_i18n_*`), работает и без .mo.

## 3. Pro-версия — модули

Все модули грузятся всегда (настройки видны как превью), рабочий функционал — при валидной лицензии (`Protect::is_trusted()`; офлайн-проверка RSA-подписанного локального ключа + повторная аттестация; grace period настраивается на сервере и зашит в ключ; сервер — только из wp-cron/админки, фронт серверу не звонит).

### 3.1 Criteria (критерии)
- CRUD критериев (slug, scale=5, required, статус), мультиязычные заголовки/описания (WPML/Polylang/locale), маппинг на категории товаров с сортировкой, глобальный фолбэк; удаление защищено если есть оценки.
- В форме: блок критериев со звёздами вместо общей оценки; серверная валидация required; итоговый рейтинг = среднее.
- В карточке отзыва: оценки по критериям; в табе товара: **сводка по критериям** (средние по одобренным отзывам).

### 3.2 Email Reminders
- Триггер: заказ → completed; очередь `pvr_email_queue`; задержка 1–90 дней (по умолч. 7); повторное напоминание (по умолч. +14 дней); крон 2р/день; пропускает отписавшихся, не-completed заказы, уже оставивших отзыв; ретраи до 3.
- Красивый брендированный шаблон: карточки товаров без отзывов (2 в ряд), ссылки с `pvr_open_review=1` + UTM; multipart plain-text; unsubscribe по подписанной ссылке (`?pvr_unsubscribe=...` с hash-токеном) — отменяет очередь и запоминает email.
- Настройки: тексты subject/heading/message на каждое напоминание, плейсхолдеры {site_name}/{customer_name}/{order_number}, исключения категорий, статистика (отправлено/ошибок/в очереди + таблица по товарам), ручная/тестовая отправка.

### 3.3 Coupons (награда за отзыв)
- Купон `REVIEW-XXXXXXXX` (WC_Coupon: percent/fixed, 1 использование, привязка к email, мин. заказ, исключения товаров/категорий/распродажи, срок 30 дней).
- Суммы по типу отзыва: текст (5) / фото (10) / видео (15) — настраиваемо.
- Логика: только **approved** отзывы; дедуп мета; отложенная выдача (cron +10 мин) для текстовых без медиа; антиспам: мин. длина текста (50) для безмедийных; зелёная плашка в форме с суммами; письмо с купоном (брендированный шаблон).

### 3.4 Widgets
- `[pvr_reviews_grid]`: product/category scope, count, only_media, orderby (date/rating/helpful), колонки по брейкпоинтам.
- `[pvr_reviews_carousel]`: то же + autoplay (задержка), пагинация scrollbar/dots, инерция/свайп/отскок, свои брейкпоинты и навигация.
- Карточки виджетов: товар (ссылка/превью/имя), кламп текста, «Read more» → модалка; переиспользуют свободные шаблоны и JS модалок.

### 3.5 Analytics
- Дашборд с фильтром периода (7/30/90/all), кэш 1 ч + ручной refresh.
- Карточки: всего одобренных, на модерации, средний рейтинг, **media coverage %**, verified %, reply rate %, helpful ratio %, coupon usage %.
- Тренд отзывов (SVG), распределение оценок, помесячная динамика, топ-10 товаров, «Needs Attention» (рейтинг ≤3).

### 3.6 Reviews Page `[pvr_all_reviews]`
- Страница всех отзывов магазина: фильтры по категории и производителю (нативный taxonomy product_brand), взаимозависимые фильтры (только те, где есть отзывы в текущем скоупе), сортировки дата/рейтинг/полезность (asc/desc), чекбоксы «с фото»/«с видео».
- Media showcase strip между фильтрами и списком; show-more (AJAX, свежие нав-блоки) + пагинация.
- **SEO-лендинги**: шаблоны H1/title/description с %category%/%manufacturer%/%count%; ручные лендинги в таблице `pvr_reviews_page_seo` (приоритет над шаблонами); `<title>` и meta description только на странице шорткода; описание только на странице 1.

### 3.7 Free→Pro upgrade
- В License-табе: ввод ключа → 3 шага (validate → download → install) с прогрессом; bootstrap (class-protect.php) с сервера; SHA-256 (X-PVR-Checksum) + RSA-подпись; бэкап + роллбэк. Реактивация: очистка опций → ключ → force refresh. Check Now со статусом, сроком действия, последней проверкой.

## 6. Что НЕ утверждать в статьях (честность)

- Не обещать «безлимит без всяких условий»: физические лимиты хостинга (upload_max_filesize, post_max_size) действуют; PVR лишь не добавляет собственных платных квот. Целевой лимит сервера плагин умеет поднимать сам (System Info).
- Бесплатность фото/видео — факт (лицензия нужна только Pro-функциям: критерии, напоминания, купоны, виджеты, аналитика, страница всех отзывов).
- Водяной знак накладывается на стороне клиента на фото; на видео — нет.
- Social Proof popup в текущем коде не подключён — в маркетинге не использовать.
- Кеш `PVREV_Cache` подготовлен, но почти не используется — не писать про «агрессивное кеширование».
- Телефон в письме админу: известная несостыковка ключей (meta `phone` vs чтение `pvr_phone`) — чинить в коде, не упоминать в статьях.
